# StreetCare: Smart Infrastructure Reporting System

**StreetCare** is a prototype application developed to address real-world road infrastructure issues by enabling communities to actively report road damage. This project emphasizes transparency and collaboration between citizens and government officials to ensure efficient public fund allocation and maintenance.

## Project Overview
Infrastructure maintenance often suffers from a lack of real-time data and transparency. **StreetCare** serves as a bridge, allowing citizens to monitor their surroundings and providing government entities with a verified, data-driven dashboard to manage repairs effectively.

## Key Features
* **Interactive GPS Mapping**: Displays real-time road conditions and report statuses using an integrated map interface.
* **Visual Damage Reporting**: Allows users to submit reports with video evidence and exact geolocation for high-accuracy tracking.
* **Admin Verification System**: Features a dedicated management flow for officials to verify reports and update repair progress.
* **Centralized Recap Dashboard**: Provides a comprehensive overview of all infrastructure reports for better decision-making.
* **Cross-Platform Accessibility**: Developed for both Windows and Android environments to maximize community reach.

## Technology Stack
* **Programming Language**: Python.
* **Core Framework**: **Kivy** (for cross-platform UI and mobile deployment).
* **Database**: **MySQL** (integrated via Backend API for data persistence).
* **Integrations**: GPS Services and Interactive Map APIs.
